# Taller 6 - GUIs con Swing y Java2D

Aplicación que lleva un diario de restaurantes.

## Ejecutar desde Eclipse

1. File > Import > General > Existing Projects into Workspace y seleccionar la carpeta taller6.
2. Abrir uniandes.dpoo.swing.interfaz.principal.VentanaPrincipal.
3. y luego Run As > Java Application.
